# Практична робота: React, Vue та Angular

Виконав(ла): Піскун Анастасія, група КН 3/1

## Мета роботи

Ознайомитися з основами роботи сучасних JavaScript-фреймворків та бібліотек React, Vue.js і Angular, створити та запустити прості вебзастосунки.

## Структура проєкту

- `react-app` — застосунок, створений за допомогою React.
- `vue-app` — застосунок, створений за допомогою Vue.js.
- `angular-app` — застосунок, створений за допомогою Angular.

## React

Для запуску:

cd react-app
npm install
npm run dev

## Vue.js

Для запуску:

cd vue-app
npm install
npm run dev

## Angular

Для запуску:

cd angular-app
npm install
npm start

## Результат

У ході практичної роботи було створено три вебзастосунки з використанням React, Vue.js та Angular. У кожному застосунку реалізовано просту сторінку з інформацією про використану технологію та лічильником натискань.

Під час виконання практичної роботи було отримано практичні навички створення, налаштування та запуску вебзастосунків на React, Vue.js та Angular, а також роботи з Git і GitHub.
